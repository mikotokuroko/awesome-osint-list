## Username and account research

- [Maigret](https://github.com/soxoj/maigret) - Collects publicly available account information associated with a username across websites.
- [Sherlock](https://github.com/sherlock-project/sherlock) - Searches for matching usernames across social networks.
- [user-scanner](https://github.com/kaifcodec/user-scanner) - Combines email and username research with MCP support.

## Email research

- [buster](https://github.com/sham00n/buster) - A toolkit for email reconnaissance.
- [holehe](https://github.com/megadose/holehe) - Checks whether an email address is associated with accounts on supported services.

## OSINT automation

- [SpiderFoot](https://github.com/smicallef/spiderfoot) - Automates OSINT collection for threat intelligence and attack-surface research.

## Research collections

- [Dark Web OSINT Tools](https://github.com/apurvsinghgautam/dark-web-osint-tools) - A collection of resources for dark-web research.
- [The Book of Secret Knowledge](https://github.com/trimstray/the-book-of-secret-knowledge) - A reference collection of manuals, cheat sheets, technical resources, and command-line tools.

## Related security tools

These projects extend beyond public-source research into general security tooling and device testing.

- [AllHackingTools](https://github.com/mishakorzik/AllHackingTools) - A collection of security tools for Termux.
- [GhostTrack](https://github.com/HunxByts/GhostTrack) - A project described by its maintainers as a location and phone-number information tool; its tracking claims have not been verified here.
- [hackingtool](https://github.com/Z4nzu/hackingtool) - An all-in-one collection of security tools.
- [PhoneSploit Pro](https://github.com/AzeemIdrisi/PhoneSploit-Pro) - Android exploitation and remote-control tooling for authorized device testing.
