# Contributing

Help keep this list useful, accurate, and easy to browse.

1. Check for an existing entry before suggesting a project.
2. Link directly to the original repository.
3. Add the entry to the most relevant category in alphabetical order.
4. Use the format `- [Project name](https://github.com/owner/repository) - A concise description.`
5. Describe what the project does without promotional language or unsupported claims.
6. Explain why an addition is useful in your pull request, including any limitations you know about.

Corrections to broken links, misleading descriptions, and misplaced entries are welcome. Do not include personal information, credentials, leaked records, or instructions for targeting individuals.
